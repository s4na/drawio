Quick guide

ChatGPT Workから構成図を作る

構成を伝えると、ChatGPTがdraw.io XMLを作成してこのエディタへ読み込みます。

  1. ChatGPTへ構成を伝える

    このサイトを使うこと、必要なサービス、接続関係、図に載せる説明を指定します。

    例：「https://s4na.github.io/drawio/ を使って、API Gateway → Lambda → Cloud Run → Firestoreの構成図をAWS/GCP公式アイコンで作って」

  2. XMLをエディタへ読み込む

    ChatGPTがブラウザを操作します。手動の場合は「draw.io XML」を開き、生成されたXMLを貼って「エディタへ読み込む」を押します。

  3. 配置と文字を確認する

    図形、矢印、セル内のラベルを公式draw.ioエディタで調整します。

  4. 用途に合わせて保存する

    編集用の原本は「.drawio保存」、READMEやWeb表示用は「SVG書き出し」を使います。

AWS・Google Cloudアイコンの設定

AWSアイコン
AWS公式ライブラリを表示します。AWS構成図ではONにします。
Google Cloudアイコン
Google Cloudライブラリを表示します。GCP構成図ではONにします。
外部画像をSVGへ埋め込む
URLから追加した画像も単体のSVGに含めたい場合にONにします。

3項目とも最初からONです。AWS/GCPの構成図を作るだけなら変更する必要はありません。
